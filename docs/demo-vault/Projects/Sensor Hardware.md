# Sensor Hardware

Bill of materials for version 1.

- Capacitive soil moisture sensor (resistive ones corrode)
- ADS1115 analog-to-digital converter over I2C
- Raspberry Pi Zero 2 W
- Waterproof enclosure and 5 V supply

The sensor feeds [[Soil Moisture]]; the board runs [[Raspberry Pi Setup]]. Energy needs: [[Power Budget]].
