# Weekly Review

Every Sunday evening, 20 minutes.

1. Empty the inbox: sort loose notes into the right hub.
2. Tick off the [[Project Roadmap]] and pick next week's one thing.
3. Plan dinners with [[Meal Planning]].
4. Write one lesson learned, as an atomic note.

Method: [[Zettelkasten Method]]. Starting point: [[Home]].
