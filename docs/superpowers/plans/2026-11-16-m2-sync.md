# M2 — Peer-to-peer sync Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Two or more devices keep the same vault of Markdown notes in step by talking directly to each other, driven headless by `sb sync`, with no silent loss or duplication of text.

**Architecture:** A new library crate `sb-sync`. A CRDT document (`loro`) mirrors the notes; one idempotent reconciliation function compares disk, document and a recorded base, and moves changes in whichever direction is needed. A sans-IO `Replica` turns peer messages into document changes and outgoing messages; an actor thread, a folder watcher and an `iroh` network adapter wrap it. The files on disk stay the truth.

**Tech Stack:** Rust 1.99 (edition 2024), `loro` 1.17, `iroh` 1.4, `iroh-mdns-address-lookup` 0.6, `notify` 8.2, `blake3` 1, `getrandom` 0.3, `tokio` 1, plus what M1 already uses.

**Spec:** `docs/superpowers/specs/2026-11-15-second-brain-design.md` — section 8 is implemented here; appendices A.2 and A.4 hold the verified facts about `iroh`, `loro`, `notify` and file locking. Section and rule numbers below refer to it.

**Revision 2026-11-16:** re-read against the merged M1 code (`main` at `3b49441`) and its final review. Added Task 0; the planner knows unreadable files and unlistable folders (Task 4); the executor creates files in the existing folder spelling (Task 5). Tasks run in the order 0, 1, 2, … 11.

## Global Constraints

- Rust only. Edition 2024. No `unsafe` (so no `std::env::set_var`: code that reads the environment has a pure twin taking a lookup closure, and tests use that).
- No `unwrap()`, `expect()` or `panic!` outside tests. Errors are values.
- Every public item has a doc comment. Functions at or under 30 lines of code and 4 parameters.
- Before every commit all three pass with no warnings: `cargo fmt --all --check`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`.
- Test names follow `should_<expected>_when_<condition>`. Commits follow Conventional Commits.
- **The files are the truth.** Sync state is derived and lives outside the vault, in the state directory. Only the sync engine writes it.
- **No silent data loss.** A file is removed only by moving it to the vault's trash. A file is replaced only after re-reading it and finding the content seen during the scan. Creating a file never replaces anything. A file that cannot be read is *blocked*, never *absent*.
- **Order of durability:** document changes are persisted before any file is written and before anything is sent to a peer; the base is persisted last.
- **Everything from a peer is untrusted**, also after authentication: note ids are checked for their format (32 lowercase hexadecimal characters), paths go through `NotePath::parse`, frame sizes are bounded. A bad entry is skipped and counted, never acted on.
- The document's peer id is never set: `loro` picks a random one per load (appendix A.4).
- Note text enters the document with `LoroText::update_by_line`, never with `update` (appendix A.4).
- Nothing waits on `Endpoint::online()` without a timeout (appendix A.2).
- Tests never touch the real state directory or the real network infrastructure: they use temporary directories, in-memory streams, or loopback addresses with relays and discovery off.
- A dependency is added only where this plan names it.
- `README.md` and `CHANGELOG.md` are updated by the task that adds a user-visible feature.
- Line endings are LF (`.gitattributes`). The code must behave the same on Windows and Linux; tests marked `#[cfg(unix)]` are written on Windows without being run there. The orchestrator runs the whole suite in a Linux container (`rust:1-bullseye`) before a task that touches the file system is marked complete, and runs the permission-sensitive tests again as an unprivileged user, because `root` ignores mode bits: such a test detects that case (the read it expects to fail succeeds), prints a note and returns.
- M1 facts every task may rely on (all in `sb-core`): `Vault::load` returns `Loaded { notes, ignored }`; `Ignored { path, reason }` with `IgnoreReason::{InvalidPath, CaseCollision, NotUtf8, TooLarge, Unreadable}`; an ignored path ending in `/` is a folder that could not be listed. `Vault::read` refuses files over `MAX_NOTE_BYTES`. `Vault::write` and `Vault::create` use the path as given: the caller resolves the spelling first with `Vault::locate` (existing note) or `Vault::adopt_folders` (new note). `Vault::rename` refuses any destination the file system finds, except a change of letter case of the note itself. `Vault::delete` moves the note to the trash.

## Review Focus

Failure modes the spec implies and that are most likely to bite a user. Each has a test in the task that owns the code.

1. **A note's file becomes unreadable** (not UTF-8, over 4 MiB, no permission, a directory in its place, or its whole folder cannot be listed). Expected: nothing is deleted on other devices and the file is untouched. → Task 4, Task 5.
2. **The process dies between persisting the document and writing files, or between writing files and saving the base.** Expected: the next start finishes the job with no duplicated text and no extra conflict copy. → Task 5.
3. **The same path is created on two devices before they meet.** Expected: identical content ends as one note; different content as a note plus a conflict copy; the same on every device. → Task 2, Task 7.
4. **A device with a full copy of the vault joins a group that already has it.** Expected: no duplicated notes and no conflict copies, whether or not the first state arrives before the wait ends. → Task 8.
5. **A peer sends rubbish after authenticating:** a path with `..`, a malformed note id, an oversized frame. Expected: skipped or disconnected; nothing outside the vault is touched. → Task 2, Task 6.

    Present { path: NotePath, content: String, hash: Hash32 },
    Blocked { path: String, reason: String },
}
pub type DiskState = std::collections::BTreeMap<NoteKey, DiskEntry>;    // a key that is not in the map is absent
#[derive(Debug, Clone, Default, PartialEq, Eq)]
pub struct DiskScan {
    pub disk: DiskState,
    pub blocked_folders: Vec<String>,        // folders that could not be listed: lowercase, `/`-separated, each ending with `/`
}
pub fn scan(vault: &Vault) -> Result<DiskScan>;

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DocAction {
    Create { path: NotePath, content: String },
    Update { id: NoteId, content: String },
    Tombstone { id: NoteId },
    SetPath { id: NoteId, path: NotePath },
    Supersede { old: NoteId, path: NotePath, content: String },         // tombstone `old` at its current text and create a new note
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum DiskAction {
    Replace { path: NotePath, content: String, expect: Hash32 },         // path: the spelling on disk
    Create { path: NotePath, content: String },                         // path: the note's display path
    Trash { path: NotePath, expect: Hash32 },
    Rename { from: NotePath, to: NotePath, expect: Hash32 },
}
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum BaseChange { Set(Hash32), Clear }
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Step {
    pub key: NoteKey,
    pub doc: Option<DocAction>,
    pub disk: Option<DiskAction>,
    pub base: BaseChange,                    // applied to `key` once the step's actions have succeeded
    pub clear_base: Option<NoteKey>,         // a rename also clears the old key
}
pub struct PlanInput<'a> {
    pub disk: &'a DiskState,
    pub view: &'a std::collections::BTreeMap<NoteKey, NoteView>,        // after claim resolution
    pub base: &'a Base,
    pub tombstoned: &'a dyn Fn(&NoteId, &Hash32) -> bool,
    pub blocked_folders: &'a [String],                                  // every key that starts with one of these is blocked
}
pub fn plan(input: &PlanInput<'_>) -> Vec<Step>;                         // ordered by key; empty when nothing has to change
```

// protocol.rs
pub const PROTOCOL_VERSION: u16 = 1;
pub const HELLO_MAX: usize = 64;
pub const FRAME_MAX: usize = 1 << 30;
pub const ALPN: &[u8] = b"secondbrain/sync/1";

#[derive(Debug, Clone, PartialEq, Eq)]
pub enum Message {
    Hello { version: u16, proof: [u8; 32] },
    Version(Vec<u8>),
    Updates { version: Vec<u8>, updates: Vec<u8> },
    Peers(Vec<DeviceId>),
}
impl Message {
    pub fn encode(&self) -> Vec<u8>;
    pub fn decode(payload: &[u8]) -> Result<Message>;                                   // SyncError::Protocol on anything malformed
}
pub async fn write_frame<W: tokio::io::AsyncWrite + Unpin>(writer: &mut W, payload: &[u8]) -> Result<()>;   // Protocol error, nothing written, when payload.len() > FRAME_MAX
pub async fn read_frame<R: tokio::io::AsyncRead + Unpin>(reader: &mut R, max: usize) -> Result<Option<Vec<u8>>>; // None on a clean end before a frame starts

// session.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Role { Dialer, Acceptor }
#[derive(Debug, Clone)]
pub struct SessionParams { pub role: Role, pub secret: Secret, pub own_id: DeviceId, pub peer_id: DeviceId }
#[derive(Debug)]
pub enum SessionEvent {
    Opened { peer: DeviceId, outbound: tokio::sync::mpsc::UnboundedSender<Message> },
    Received(Message),
    Closed,
}
/// Authenticates, then relays messages until either side closes. `on_event` sees `Opened` once after a successful
/// handshake, then every received message, then `Closed` exactly once if `Opened` was seen.
pub async fn run_session<R, W>(reader: R, writer: W, params: SessionParams, on_event: impl FnMut(SessionEvent) + Send) -> Result<()>
where R: tokio::io::AsyncRead + Unpin + Send, W: tokio::io::AsyncWrite + Unpin + Send;
```

Encoding of a payload: one type byte, then the body.

| Type byte | Message | Body |
| --- | --- | --- |
| 1 | `Hello` | version, `u16` big-endian; proof, 32 bytes (35 bytes in all) |
| 2 | `Version` | the version bytes |
| 3 | `Updates` | length of the version, `u32` big-endian; the version; the updates |
| 4 | `Peers` | zero or more device ids of 32 bytes each |
